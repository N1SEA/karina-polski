# Polski na pobyt

PWA для підготовки до співбесіди на pobyt stały (традиції, свята, культура, історія Польщі).
Інтерфейс українською, питання польською з перекладом і вимовою кирилицею.

## Що всередині

- **Вчити** — картки з інтервальним повторенням і підказками-сходинками, «Склади відповідь», «Пропущені слова». Без лімітів.
- **Тести** — білети як у ПДР, іспит (20 питань, 20 хв, до 2 помилок), марафон без кінця, мої помилки, топ-питання, випадкові білети.
- **Чат** — питання з бази по черзі; відповідь своїми словами (голосом або текстом), AI оцінює і ставить 1–2 уточнення, потім взірцева відповідь.
- **Розмова** — вільна розмова з AI-урядницею (Claude) на обрану тему.
- **Моя історія** — розповідь про себе з AI-перевіркою.
- План на 30 днів, серія днів, резервна копія прогресу у файл.

База даних не потрібна: прогрес зберігається на телефоні (localStorage), є експорт/імпорт копії.

## Локально

```bash
npm install
npm test
npm run dev
```

Відкрити http://localhost:5174. Для AI створіть `.env.local`:

```
ANTHROPIC_API_KEY=sk-ant-...
APP_PASSCODE=будь-який-код
```

## Деплой на Vercel (сайт + AI) — рекомендовано

1. Імпортувати репозиторій у Vercel (Framework: Other, без build-команди).
2. Environment Variables: `ANTHROPIC_API_KEY` (ключ Claude — лише тут, на сервері), `APP_PASSCODE` (будь-який код).
3. Надіслати користувачці посилання `https://ПРОЄКТ.vercel.app/#/setup/КОД` — застосунок сам запам’ятає код
   (його можна також ввести в «Я → Налаштування»). Потім «Додати на головний екран».

Ключ API ніколи не потрапляє на телефон: телефон звертається до `/api/examiner`, а сервер — до Claude.

## GitHub Pages (лише статичний сайт)

Pages не запускає сервер, тож AI працює через Vercel:

1. У `index.html` вписати `<meta name="api-base" content="https://ВАШ-ПРОЄКТ.vercel.app">`.
2. У Vercel додати змінну `ALLOW_ORIGIN=https://ВАШ-ЛОГІН.github.io`.
3. Settings → Pages → Deploy from branch → `main` / root.

## Оновлення

Після зміни файлів збільшити `VERSION` у `sw.js`, щоб телефон підтягнув нову версію.
Банк питань — `data.js` (`q/a` польською, `qu/au` українською, `at` — вимова, наголошена голосна велика; `top: true` — часті на співбесіді).
